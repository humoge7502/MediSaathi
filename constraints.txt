# The tier declares lower bounds (>=) so development stays flexible; CI and
# any deployment pin through this file so fresh installs cannot float:
#
#   pip install -c constraints.txt -e packages/contracts -e "apps/api[dev]"
#
# Bump deliberately: change a pin here, run `make test && make demo-check`,
# and commit the result. pip-audit in CI still scans for advisories.
#
# Versions recorded 2026-10-29 from the verified environment: 466 pytest
# passed, 5/5 data gates, 111 sealed demo cases, parity 164/164. The previous
# record (2026-09-10, 107/107 tests) was three months and 26 FastAPI minor
# versions behind, which is the reason this file exists — a floating install
# in CI silently disagreed with the machine the gates were run on.
#
# Two entries are load-bearing beyond the obvious:
#  - starlette is transitive (via fastapi) but pinned because the rate limiter,
#    body-size guard and security headers are `BaseHTTPMiddleware` subclasses,
#    whose contract has changed across starlette majors before.

#    declares httpx2 in its own `full` extra; with only `httpx` installed, every
#    pytest run opens with a StarletteDeprecationWarning. `httpx` itself stays
#    pinned: the live-vision client and `tools/bench.py` use it directly, and
#    0.28.1 is current for that line.
