# ACM-VIT Design Analysis

**Access date:** 2026-09-10  
**Source:** <https://www.acmvit.in/>  
**Scope:** publicly accessible homepage content only; no proprietary assets or code were copied.

## Observations

The accessible ACM-VIT page presents a focused project/initiative surface rather than a dense application dashboard. Its content foregrounds what a project is, why it matters, and a clear visit action. The broader public search description emphasizes impactful technology, innovation, and community.

## Transferable principles

- **One clear narrative:** lead with the user problem and outcome before implementation detail.
- **Progressive disclosure:** keep the first screen legible; move provenance, methodology, and failure details into deliberate secondary surfaces.
- **Strong action hierarchy:** one primary launch action, with secondary navigation for context.
- **Project-led presentation:** name the system, explain its purpose, then expose evidence and implementation.
- **Fast comprehension:** content should remain understandable to a reviewer scanning for 30 seconds.

## MediSaathi adaptation

- The landing page uses one product sentence, one primary scan action, and a judge walkthrough action.
- The scan page makes the safety state visually dominant, then exposes extracted fields, findings, plan, price, and provenance in sequence.
- Refusal and confirmation are designed as clear states rather than hidden error details.
- The system uses calm clinical tokens, high-contrast mode, keyboard-visible focus, semantic landmarks, and reduced-motion handling.

## What not to copy

- ACM-VIT branding, typography, illustrations, layout details, or event-specific language.
- Any visual asset or interaction that would imply affiliation.
- A marketing-first page that hides the prototype's no-auth and synthetic-data limitations.

## Limitations

This analysis is based on the publicly accessible page returned on the audit date, not a full browser/performance/accessibility study across every ACM-VIT route. No claims are made about inaccessible or dynamic content.
