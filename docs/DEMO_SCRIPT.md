# Demo Script (90 seconds) - rehearsal-ready

Narrator = team lead. Driver never leaves the keyboard. Cached mode default;
live path shown once mid-script to prove the cache hides nothing.

| Beat | Sec | Action on screen | Narration |
|---|---|---|---|
| Hook | 0-10 | Hold printed Rx; then /scan | "This is what a million families hold at every hospital exit. Most cannot read it. None can verify it." |
| Capture | 10-20 | Pick RX-001; processing steps | "Extraction with per-field confidence. Below threshold goes to a confirmation queue - not a guess." |

| Voice | 40-55 | Tamil audio plays | "The plan speaks the patient's language, and not one word of the dose is model-generated." |
| Price + ADR | 55-70 | Price card; ADR draft | "Same therapy as a Jan Aushadhi generic. A side effect becomes a PvPI report in one tap." |
| Refusal | 70-85 | RX-006; refusal screen; /metrics | "When it cannot verify, it refuses. That discipline is measured - here is the benchmark." |
| Close | 85-90 | Eval table; repo URL | "Verification-first medication intelligence, built and measured in 24 hours." |

## Failure drills (rehearsed at hour 20)

1. WiFi dead -> cached mode hotkey; line: "We built this to run without a network."
2. Quota exhausted -> cached tier; line: "The system degrades; it does not die."
3. Projector broken -> contrast mode; 120% zoom preset.
4. Laptop freeze -> second laptop, same image, demo-check green; 60s swap.
5. Unknown question -> Q&A bank; else "honest scoping is part of our method."
